Reset your password

Parent accounts: Ask the other parent to sign in, open Family accounts, and choose Create password reset link beside your account. Open that private link to choose a new password. Reset links work once and expire after one hour.

Student accounts: Your parent can set a new password for you in Family accounts.

If both parents are locked out, ask for a new private reset link in this VenvLearning setup chat.

Use the exact email address used to create your account. Recovery is through private links; automatic reset emails are not enabled.
